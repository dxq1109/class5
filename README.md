# 三峡大学 · 计算机科学与技术2025级5班 班级网站

班级答辩用的**班级相册**：梦幻天空背景 + 玻璃拟态卡片，把照片按活动分册成一本本相册，配 3D 奖状环廊、项目招揽与期末复习厅。

展厅分布：**序厅橱窗 · 班级相册 · 荣誉殿堂 · 项目展示厅 · 班级社区 · 期末复习 · 留言墙 · 聊天室 · 游戏厅**。

## 🚀 快速开始

需要 [Node.js](https://nodejs.org/zh-cn)（16 以上版本）。

```bash
npm install     # 安装依赖（只需一次）
npm start       # 启动网站
```

启动后：
- 本机访问：<http://localhost:3000>
- **分享给同学**：让他们访问 `http://<你的局域网IP>:3000`（把 IP 换成你电脑的 IP，手机和电脑连同一个 WiFi 即可）

启动时控制台会显示地址。首次运行会自动把 `images/` 和 `videos/` 里的现有素材导入数据库。

> ⚠️ **不要用 VSCode 的 Live Preview / 文件预览直接打开 index.html**：
> 照片、社区、弹幕等数据都来自后端接口 `/api/*`，静态预览拿不到数据，页面会显示「未连接到服务器」。
> 正确步骤：在 VSCode 终端里运行 `npm start`，然后用浏览器打开 **http://localhost:3000**。
> （想在 VSCode 里看：先启动服务，再按 `Ctrl+Shift+P` → 输入 `Simple Browser: Show` → 填 `http://localhost:3000`。）

## 📮 分享给班级（三种方式）

**方式一：局域网演示（最简单，适合课堂/当场）**
电脑和同学连同一个 WiFi，运行 `npm start`，让同学访问 `http://<你电脑IP>:3000`（启动时控制台会显示 IP）。适合当天答辩现场，不用部署。

**方式二：云服务器（推荐长期用，全班随时能访问）**
国内推荐腾讯云 / 阿里云的「轻量应用服务器」（学生价几十元/年），系统选 Linux 或装宝塔面板：
1. 把整个项目文件夹上传到服务器（或用 `git clone` 你的仓库）。
2. 服务器上执行：
   ```bash
   npm install
   npm start        # 或 pm2 start server.js --name class-site
   ```
3. 开放 3000 端口，把 `http://服务器IP:3000` 发到班群即可；有域名就配 nginx + HTTPS 更好。
4. **务必先改 `config.json` 里的 `adminPassword`**。

**方式三：免费托管（临时演示，数据会重置）**
[Render](https://render.com) / [Railway](https://railway.app) 可直接跑 Node 项目（把本仓库推上去，启动命令 `npm start`，监听端口用环境变量 `PORT`）。注意：免费版磁盘不持久，`data/` 和 `uploads/` 重启会清空，只适合临时 demo，不适合长期存放班级照片。

> 数据安全提示：本网站数据存在 `data/db.json` + `uploads/` 两个地方，**备份 = 复制这两个文件夹**。长期用建议放云服务器，并定期备份。

## 🌐 部署到公网服务器（详细）

1. 把整个文件夹上传到服务器（`node_modules` 可以不传，在服务器上重新 `npm install`）。
2. 安装依赖并启动：
   ```bash
   npm install
   npm start
   ```
3. 长期运行推荐用 [pm2](https://pm2.keymetrics.io/)：
   ```bash
   npm install -g pm2
   pm2 start server.js --name class-site
   pm2 save && pm2 startup
   ```
4. 有域名/nginx 时，把域名反向代理到 `127.0.0.1:3000` 即可；务必加 HTTPS。

## ⚙️ 配置（`config.json`）

```json
{
  "port": 3000,              // 网站端口
  "adminPassword": "admin123",  // ⚠️ 站长密码：删除任何留言/照片时用，上线前务必修改！
  "maxUploadMB": 50,         // 单文件上传上限
  "siteName": "三峡大学 计算机科学与技术2025级5班",
  "chatHistoryLimit": 1000   // 聊天记录保存条数
}
```

也可以用环境变量覆盖端口：`PORT=8080 npm start`（Windows PowerShell：`$env:PORT=8080; npm start`）。

## 🗄️ 数据存在哪、怎么备份

| 内容 | 位置 |
|---|---|
| 数据库（照片/留言/聊天记录） | `data/db.json` |
| 同学们上传的文件 | `uploads/` |
| 原有素材 | `images/`、`videos/`（只读展示，不会改动） |

**备份 = 复制 `data/` 和 `uploads/` 两个文件夹**。恢复时放回原位即可。

## 🔑 删除权限说明

- 同学们上传照片 / 留言后，会获得一个**专属删除码**（存在自己的浏览器里），只能删自己的内容。
- 站长可用 `config.json` 里的密码删除任何内容（在删除按钮弹出的输入框里输入站长密码）。
